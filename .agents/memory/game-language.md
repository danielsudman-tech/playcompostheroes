---
name: Printed-card game language
description: Product wording constraints for the five collectable functions and the distinct printed layer property.
---

Call the five collectables **functions**, and their board positions **function slots**. Do not describe them as layers, categories, matrix rows or components in player-facing copy.

**Why:** the creator asked for one plain vocabulary matching the printed cards, including home, decisions, rules, progress and results.

**How to apply:** preserve this wording when adding or changing any player or host screen. Use one shared ordering for function displays and pickers.

Keep a card's actual **layer** distinct from its function. Rules such as Critical Mass's same-layer condition must still refer to the real layer.

**Why:** the creator explicitly warned that the printed layer property is a different game concept, not another name for a function slot.

**How to apply:** do not mechanically replace “layer” in real card rules or factual compost trivia.

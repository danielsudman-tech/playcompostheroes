---
name: Event results privacy
description: Product boundary for public Event progress and participant results.
---

An Event code may reveal aggregate table status, but individual results belong behind the participant's saved seat token. Never add live hands, hidden decisions, questions, or host-only alerts to the public Event summary. Face-up discard piles and their history remain public within a game; a personalized notification about a discarded card does not make that card secret from the table.

**Why:** Guests need to know when other tables finish without gaining access to active games or host information. Existing card-game rules already make played and discarded cards observable.

**How to apply:** Keep the gathering view on the public phase/count contract plus the viewer's token-scoped own-game state; consider whether newly added game details are hidden before redacting or displaying them.
